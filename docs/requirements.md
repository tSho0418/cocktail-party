# 要件定義書: Cocktail Party

用語は [CONTEXT.md](../CONTEXT.md) に従う。要件 ID(FR / NFR / OOS)は、技術スタックの選定時に根拠として参照する。

## 1. 目的と前提

| ID | 内容 |
|---|---|
| BG-001 | カクテルのレシピと写真を共有する日本語の Web SNS を作る。 |
| BG-002 | 主な利用者は、自宅で飲む人(今ある材料で作れるカクテルを探す)。副の利用者は、作品を発信するプロのバーテンダー。 |
| BG-003 | 個人開発のポートフォリオが目的。収益化は考えない。 |
| BG-004 | 一般公開する。規模は Recipe 数百〜数千件、同時アクセス数人〜数十人。運用費は月500円以内(NFR-008)。 |
| BG-005 | 日本語のみ、Web のみ(レスポンシブ)。 |

## 2. 機能要件

### 2.1 Recipe

| ID | 内容 |
|---|---|
| FR-001 | Member は Recipe を投稿できる。投稿した時点で公開される。 |
| FR-002 | Recipe は常に1杯分である。 |
| FR-003 | Recipe は、タイトル(50字まで)、紹介文(500字まで)、Main Photo(1枚、必須)、追加の Photo(最大3枚、任意)、液体の Ingredient と Mix Ratio、手順を持つ。 |
| FR-004 | 液体の Ingredient は最低1つ、最大20個。同じ Ingredient を同じ Recipe に重複して入れられない。 |
| FR-005 | Mix Ratio は 0.1 以上 99.9 以下、小数点以下1桁まで。単位は持たない。 |
| FR-006 | 手順は、番号付きの複数ステップ。最低1ステップ、最大10ステップ、1ステップ200字まで。液体でない材料(ミント、ビターズ、ガーニッシュなど)は、手順の文章に書く。 |
| FR-007 | Main Photo がない Recipe は保存できない。 |
| FR-008 | 投稿者は、自分の Recipe を編集・削除できる。削除すると、紐づく Like と Save も削除する。Report は記録として残す。 |

### 2.2 Ingredient

| ID | 内容 |
|---|---|
| FR-010 | Ingredient は、名前と度数(%)を持つマスタとして管理する。酒類の Ingredient は、Base になるかどうかの属性も持つ。 |
| FR-011 | 初期マスタとして、酒類約50種類(主要なスピリッツ、リキュール、ワイン、ビール)と、度数 0% の材料約30種類(ジュース、シロップ、炭酸など)を用意する。 |
| FR-012 | Member は、度数 0% の Ingredient を、承認なしで新規登録できる。 |
| FR-013 | 酒類の Ingredient は、Administrator だけが登録できる。 |
| FR-014 | Ingredient の新規登録時に、類似する既存の Ingredient をサジェストして、重複を防ぐ(強制はしない)。 |
| FR-015 | Administrator は、Ingredient の度数を編集できる。編集すると、その Ingredient を使うすべての Recipe の自動計算の値を再計算する。上書きした値が新しい範囲(FR-022)を外れた Recipe は、上書きを破棄して自動計算の値に戻す。 |

### 2.3 度数と Base

| ID | 内容 |
|---|---|
| FR-020 | Recipe の Alcohol Content は、各 Ingredient の度数と Mix Ratio の加重平均で自動計算する。氷の溶けは考慮せず、「目安」と表示する。酒類の Ingredient を含む Recipe では、丸めた値が 0.0% になる場合に 0.1% とする(酒入りの Recipe を 0% と表示しない)。 |
| FR-021 | 酒類の Ingredient を含む Recipe では、投稿者が Alcohol Content を上書きできる。上書きした値は、自動計算の値と区別して表示する(「投稿者による修正値」)。 |
| FR-022 | 上書きできる範囲は、0% を超え、含まれる Ingredient の最高度数以下。 |
| FR-023 | 材料を編集しても、上書きした値は残る。「再計算する」操作で、自動計算の値に戻せる。 |
| FR-024 | 酒類の Ingredient を含まない Recipe は、Alcohol Content が 0% に固定され、上書きできない。 |
| FR-025 | Non-alcoholic は、「酒類の Ingredient を1つも含まない」ことで決まる。Member は直接設定できない。 |
| FR-026 | Base は、Recipe に含まれる、Base の属性を持つ Ingredient から導出する。複数の Base を持つことがある。 |

### 2.4 Photo

| ID | 内容 |
|---|---|
| FR-030 | 受け付ける形式は JPEG、PNG、WebP。利用者は1枚10MBまで選べる。ブラウザが 4.5MB 未満に縮小してから送り、サーバーが受け取る上限は 4.5MB とする。 |
| FR-031 | アップロードされた Photo は、サーバーで再エンコードして位置情報(EXIF)を削除する。 |
| FR-032 | アイコン画像にも、FR-030 から FR-033 を適用する。 |
| FR-033 | 元のファイルは保存しない。再エンコードした、一覧用と詳細用の2サイズだけを保存する。 |

### 2.5 検索と閲覧

| ID | 内容 |
|---|---|
| FR-040 | トップは、全 Recipe を新着順に並べた一覧と、検索の入口。 |
| FR-041 | 材料検索: 複数の Ingredient を指定すると、すべてを含む Recipe(AND)を表示する。除外指定は持たない。 |
| FR-042 | 「手持ちの材料だけで作れる」検索: 指定した Ingredient だけで構成される Recipe を表示する。判定は液体の Ingredient だけで行う。 |
| FR-043 | キーワード検索: タイトル、紹介文、Ingredient 名、手順の文章を対象にする。 |
| FR-044 | 絞り込み: Base(どれかに一致すれば表示)、度数の範囲(上書きした値があればその値で判定)、Non-alcoholic。 |
| FR-045 | 並び順: 新着順と Like 数順。 |
| FR-046 | 非ログインの閲覧者も、Recipe の一覧、検索、詳細、Member のプロフィールを閲覧できる。 |

### 2.6 Member とソーシャル機能

| ID | 内容 |
|---|---|
| FR-050 | ログインは、Google と LINE のソーシャルログインのみ。メールアドレスとパスワードによるログインは持たない。LINE がメールアドレスを返さなくても、Member を作れる。 |
| FR-051 | 1つの Member は1つの提供元と対応する。提供元を変えると別の Member になる。ログイン画面に、その旨を表示する。 |
| FR-052 | 初回ログイン時に、Username を設定する。メールアドレスは公開しない。 |
| FR-053 | Username は一意で、大文字と小文字を区別しない(`alice` と `Alice` は同じ)。半角英数字とアンダースコア、3〜20文字。後から変更できる。 |
| FR-054 | プロフィールは、Username、自己紹介文(200字まで)、アイコン画像、投稿した Recipe、Follow している Member とフォロワーの一覧を持つ。一覧は誰にでも見える。 |
| FR-055 | Member は Recipe に Like を付けられ、取り消せる。Like は数だけ表示し、誰が付けたかは表示しない。自分の Recipe には付けられない。 |
| FR-056 | Member は Recipe を Save できる。Save 一覧は、本人にだけ見える。 |
| FR-057 | Member は他の Member を Follow できる。自分自身は Follow できない。Follow はトップの表示に影響しない。 |
| FR-058 | Member は退会できる。確認画面を設け、猶予期間は設けない。退会すると、その Member の Recipe、Photo、Like、Save、Follow をすべて削除する。 |

### 2.7 年齢ゲート

| ID | 内容 |
|---|---|
| FR-060 | 初回アクセス時に Age Gate を、モーダルとして重ねて表示する。20歳以上であることを自己申告させる。 |
| FR-061 | 同意は、Cookie に30日間保持する。 |
| FR-062 | Recipe 詳細ページの本文は、Age Gate の表示の有無にかかわらず HTML に含め、検索エンジンが読めるようにする。 |

### 2.8 Report と管理

| ID | 内容 |
|---|---|
| FR-070 | Member は Recipe を Report できる。理由は、不適切な画像、他人の写真・レシピの盗用、スパム、その他の4種類。任意の自由記述(200字まで)を付けられる。 |
| FR-071 | 同じ Member は、同じ Recipe を1回だけ Report できる。 |
| FR-072 | Report は、状態(未対応、対応済み、却下)を持つ。送信した Member は、Administrator に見える。 |
| FR-073 | Administrator は、管理画面で Report の一覧を見られる。 |
| FR-074 | Administrator は、Recipe を削除できる。投稿者への通知は行わない。削除後も、Report は記録として残す。 |
| FR-075 | Administrator は、Member を Suspension にできる。Suspension 中の Member は、ログインできず、Recipe は非表示になり、Follow の一覧やプロフィールにも出ない。解除すると元に戻る。 |
| FR-076 | Administrator は、酒類の Ingredient の登録と、Ingredient の度数の編集を、管理画面で行える。 |
| FR-077 | Administrator は、Member と同じログインに、管理者の権限を付けた Member とする。 |
| FR-078 | 退会した Member が受けた Report は、Recipe の内容を含めず、「退会済み」の記録として残す。送った Report は、送信者の識別だけを消して残す。 |

### 2.9 画面

| 区分 | 画面 |
|---|---|
| 誰でも | トップ(新着一覧と検索)、検索結果、Recipe 詳細、Member のプロフィール、利用規約、プライバシーポリシー、Age Gate(モーダル) |
| Member | ログイン(2つの提供元のボタン)、初回の Username 設定、Recipe の投稿・編集、Save 一覧、プロフィールの編集、退会、Report の送信 |
| Administrator | Report の一覧、酒類 Ingredient の登録と度数の編集、Member の Suspension、Recipe の削除 |

### 2.10 共有

| ID | 内容 |
|---|---|
| FR-080 | Recipe 詳細ページは、OGP に対応する。タイトルと Main Photo を、リンクを貼ったときに表示する。 |
| FR-081 | 共有ボタンは持たない。 |

## 3. 非機能要件

| ID | 内容 |
|---|---|
| NFR-001 | 性能: Recipe の一覧と詳細は、通常の回線で2秒以内に表示開始する。 |
| NFR-002 | 可用性: 稼働率は保証しない。計画的な停止を許容する。 |
| NFR-003 | バックアップ: データベースを GitHub Actions で毎日 `pg_dump` し、R2 の別バケットに14日分を残す。Neon の復元履歴(6時間)には頼らない。画像は保存先の冗長化に任せる。復旧の訓練はしない。 |
| NFR-004 | セキュリティ: HTTPS。画像アップロードの形式検証。Report の重複防止(FR-071)。 |
| NFR-005 | アクセシビリティ: キーボード操作ができる。画像の代替テキストを、Recipe のタイトルから生成する。WCAG への準拠は目標にしない。 |
| NFR-006 | レスポンシブ: スマホの縦画面と PC で使える。写真のアップロードは、スマホのブラウザから行える。 |
| NFR-007 | SEO: Recipe 詳細ページは、検索エンジンに本文が読まれる(FR-062)。一覧とマイページは対象外。 |
| NFR-008 | 運用費: 月500円以内。独自ドメインの年額を12で割った額を含む。サーバー側は無料枠のみで運用する。 |
| NFR-009 | 法務: 利用規約とプライバシーポリシーを、公開前に用意する。利用規約で、他人の写真の無断掲載を禁止する。 |

## 4. 公開時の初期データ

| ID | 内容 |
|---|---|
| DT-001 | 初期の Ingredient マスタ(FR-011)。 |
| DT-002 | デモ用の Recipe を、約20件投稿しておく。Base と度数に幅を持たせ、Non-alcoholic を3件以上含める。 |

## 5. 対象外(OOS)

| ID | 対象外とするもの |
|---|---|
| OOS-001 | コメント、ダイレクトメッセージ、通知(Like や Follow があっても通知しない)。 |
| OOS-002 | 下書き、編集履歴。 |
| OOS-003 | カクテルの上位概念(Cocktail マスタ)。同名の Recipe は、独立したものとして並ぶ。 |
| OOS-004 | 技法、グラス、味の傾向、難易度の属性。 |
| OOS-005 | 人気順のトップ、フォロー中のフィード。 |
| OOS-006 | 多言語、ネイティブアプリ、収益化、EC 連携。 |
| OOS-007 | 管理画面での Ingredient の統合と、酒類以外の編集。 |
| OOS-008 | Member による、酒類の Ingredient の追加依頼。 |
| OOS-009 | Recipe への分量の単位(ml、oz など)と、全体の量。 |
| OOS-010 | 複数の提供元の結びつけ、メールアドレスによる同一人物の判定。 |
| OOS-011 | SNS への共有ボタン。 |
| OOS-012 | Apple ログインと X ログイン(Apple は年額の費用、X は従量課金のクレジットが要るため)。 |

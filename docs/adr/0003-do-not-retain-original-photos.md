# 元の画像を保存しない

公開サービスで、スマホの写真に含まれる位置情報(EXIF)が漏れることを避けるため、元のファイルは保存しない。ブラウザが 4.5MB 未満に縮小して送り、サーバーが再エンコードして EXIF を削除し、一覧用と詳細用の2サイズだけを R2 に保存する(FR-030〜FR-033)。

## Considered Options

- **署名付き URL で R2 へ直接アップロードし、サーバーで処理して元を削除する**: 見送った。位置情報つきの元のファイルが、処理の間だけ R2 に残る。処理に失敗すると残り、掃除の仕組みが要る。
- **元のファイルを非公開で保存する**: 見送った。位置情報を含むファイルを持ち続けるので、漏えいの危険が残り、R2 の無料枠(10GB)も早く埋まる。

## Consequences

- 一度捨てた元の画像は戻せない。後から大きな画像が要るようになっても、再エンコード済みの2サイズからは作れない。
- Vercel 関数の本文は 4.5MB までなので、「10MB まで」は、ブラウザが縮小する前の選択の上限になる。サーバーが守る上限は 4.5MB。
- サーバーの再エンコードで EXIF の削除を保証するので、ブラウザの縮小を迂回されても漏れない。

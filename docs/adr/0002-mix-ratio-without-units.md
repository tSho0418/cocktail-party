# Mix Ratio は単位を持たない

Recipe の材料は、ml や oz といった分量の単位ではなく、液体の Ingredient ごとの相対的な割合(Mix Ratio、0.1〜99.9、小数点以下1桁まで)で表す。度数の計算(FR-020)は、単位換算が要らない加重平均になり、ダッシュなど換算できない単位の扱いに悩まずに済む。

## Considered Options

- **ml、oz、tsp などの単位つきの分量**: 見送った。一般的なレシピの形だが、oz から ml への換算、ダッシュのような換算できない単位、氷の溶けの扱いが、度数の計算を複雑にする。

## Consequences

- 全体の量を持たないので、Recipe からは、ml でいくら注ぐかが分からない。再現する人が、自分のグラスに合わせて決める。
- ミントの葉、ビターズ、ガーニッシュなど液量で表せない材料は、Ingredient ではなく手順の文章に書く(FR-006)。材料検索(FR-041、FR-042)の対象にならない。
- 後から単位つきの分量へ移るとき、既存の Recipe の割合を、どの量に直すかが決まらない。

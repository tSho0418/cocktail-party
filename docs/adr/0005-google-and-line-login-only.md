# ログインは Google と LINE のみ。1つの Member は1つの提供元と対応する

Apple は年額 99 USD、X は従量課金のクレジットが必要で、月500円(NFR-008)に収まらないため外し、追加費用のない Google と LINE だけにした。ログインは Better Auth をアプリの中に置き、アカウントとセッションを、同じ Neon のデータベースに持つ。1つの Member は1つの提供元とだけ対応し、提供元を変えると別の Member になる(FR-050、FR-051)。

## Considered Options

- **4つの提供元(Google、LINE、Apple、X)**: 見送った。費用が運用費の上限を超える。
- **複数の提供元の結びつけ**: 見送った。結びつけの画面、最後の1つを解除できない制約、結びつけ済みの提供元の重複登録の扱いが要る。LINE や Apple は、メールアドレスを返さないことがあり、メールアドレスで同一人物を判定できない。
- **Neon の管理型 Better Auth**: 見送った。外部のサービスに依存し、Suspension、Administrator の権限、退会時のデータ削除を、アプリのデータと同じトランザクションで扱えない。

## Consequences

- 提供元のアカウントを失った Member は、元のデータに戻れない。ログイン画面に、提供元を変えると別のアカウントになることを表示する。
- Apple と X は、OOS-012 に記録した。後から足すことは、Better Auth の設定で可能だが、費用を再び検討する。
- LINE には `openid` のスコープだけを要求する(`email` は LINE 側でメールアドレス取得の申請が要り、`profile` の名前と画像もアプリは保存しないため、要求しない)。
- LINE がメールアドレスを返さない場合でも、Member を作れることを、実装前に確かめる(S1)。
- LINE の開発ガイドラインは、ユーザーが退会したときに、アプリがユーザーに代わって連携を解除(deauthorize)することを必須としている。LINE の Member が退会すると、削除のコミットの後に、Member の LINE のアクセストークンで `POST https://api.line.me/user/v1/deauthorize` を呼ぶ(チャネルアクセストークンは、チャネル ID とシークレットから都度発行するステートレスのもの)。トークンは Member を削除すると account ごと消えるので、削除の前に読む。外部の通信なので、トランザクションの外で行い、失敗しても退会は成功させる(失敗はログに残すが、トークンは出さない)。アクセストークンの有効期限は30日、リフレッシュトークンは90日で、リフレッシュしても延びない。Better Auth のセッションはスライディングなので、毎日使う Member は OAuth をやり直さない。このため、**最後の OAuth ログイン**から90日を過ぎた Member は連携を解除できず、LINE アプリの「設定 > アカウント > 連携アプリ」に残る。退会ページ、利用規約、プライバシーポリシーに、解除できない場合があることと、その手順を書く。退会の前に LINE で再ログインさせる案は、重いので採らない(判断事項として README に残す)。
- Google の Sign in with Google のベストプラクティスは、アカウントの削除時に、取得したアクセストークンとリフレッシュトークンを失効することを求めている。Google の Member が退会すると、同じ構造で(削除のコミット後、ベストエフォート)、アクセストークンを `POST https://oauth2.googleapis.com/revoke` で失効させる。`accessType: 'offline'` を設定していないのでリフレッシュトークンは無く、失効できるのはアクセストークンだけである。アクセストークンは約1時間で切れ、切れたものは失効させても何も変わらないので送らない。このため実際に効くのは、最後の Google ログインから約1時間以内の退会に限られる。全員の連携を切るには `accessType: 'offline'` でリフレッシュトークンを保存する必要があるが、保存するものと同意画面が変わるので、今回は採らない。
- 退会時の連携解除と失効は、実際の LINE と Google では試していない。LINE のログインは、Preview で一度失敗した(原因は未確認。`email` スコープが原因という仮説があり、`openid` だけにして再確認する)。Google のログインは Preview で確認済み。
